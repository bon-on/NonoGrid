# NonoGrid

A small nonogram (paint-by-numbers) logic puzzle built with Flutter. New levels receive a random seed matched to their grid-size difficulty.
The seed is saved, so reopening, restarting or replaying keeps the same puzzle.
Every puzzle is uniquely solvable by line logic alone, so you never have to guess.

Runs in the browser (GitHub Pages) and on iOS/Android. No ads, no network,
no accounts; progress is stored locally on the device.

## How to play

- The numbers next to each row and above each column list the lengths of the
  runs of filled cells in that line, in order. `0` means the line is empty.
- Fill cells so every row and column matches its clue. Mark cells you know are
  empty with an X to help yourself; X marks do not count against you.
- A clue turns grey (and its line flashes with a check) once the filled runs
  in its line match it. Filling more cells than a line's clue adds up to
  shakes the board.
- Solving the puzzle blooms the picture into colour and unlocks the next
  level.

### Stars, XP, album and themes

- Each level awards up to 3 stars: solve it, never let **Check** find a
  wrong cell, and finish within the par time (1.5 s per cell + 20 s).
- Solving earns painter XP (first clear: grid size x 2 + stars x 5; replays
  give 3 XP plus 5 per new star). Painter levels unlock paper themes:
  Notebook (Lv 1), Kraft (Lv 3), Washi (Lv 6) and Midnight (Lv 10).
- **Album** collects every solved picture in colour; **Levels** shows a map
  of levels with their stars (arrows + Enter to pick); **Themes** switches
  paper. Esc closes any of them.
- After a win a summary shows time, best, stars, XP and new unlocks
  (Enter: next puzzle, Esc: look at the picture).
- **Album sets**: every 10 levels form a named set (Set 1 Sketchbook = levels
  1-10, Set 2 Garden = 11-20, ...). The album shows N/10 and a bar per set,
  hides unsolved pictures behind blank tiles, and pins the next picture that
  completes a set (Enter or Play opens it). Completing a set grants a
  one-time +50 XP bonus, shown on the summary.

### Daily puzzle and streak

- One daily puzzle per **local calendar date**, the same for every player on
  that date (8x8 Mon-Tue, 10x10 Wed-Fri, 12x12 Sat-Sun). It is generated by
  the same line-solvable generator from a seed derived from the date
  (`harness/adrs/adr-daily-puzzle.md`).
- The daily card on the main screen shows today's state (New / In progress /
  Done) and your streak; click it or press **D**. The daily board is saved
  separately, so your level board is untouched.
- Streak: solve the daily on consecutive days. Miss a single day and your
  **grace** keeps the streak alive; the grace refills after 7 daily solves.
  Best streak and total solves appear in the daily card and the album.
- Reward: normal stars and first-clear XP plus a daily bonus of
  10 + 5 x min(streak - 1, 4) XP (10-30).
- The daily summary shows the next goal ("Come back tomorrow for streak N")
  and **Copy result** (C), which copies text such as
  `NonoGrid Daily 2026-11-08: 12x12 in 3:21, 3/3 stars, streak 4` plus the
  game link of the build (GitHub Pages link; on CrazyGames only the
  CrazyGames page reported by the SDK; none on GamePix). The game never
  opens that link.
- Changing the device clock never crashes or makes a streak negative;
  solving a date earlier than your last solved daily gives no reward.


On reopening, a valid unfinished board resumes with the same puzzle, marks,
elapsed time and mistake state. If the selected level was completed and no
unfinished board remains, the next unlocked level opens even if Next was not
pressed before closing. Album/map thumbnails show the assigned puzzle.

### Controls

| Action | Touch / mouse | Keyboard |
| --- | --- | --- |
| Fill a cell | Tap/click in **Fill** mode | Space |
| Mark X | Tap in **Mark X** mode, or right-click | X |
| Paint a line | Drag (locks to the row or column you start moving in) | - |
| Move cursor | - | Arrow keys |
| Undo last stroke | Undo button | U |
| Restart puzzle | Restart button | R |
| Next level (after a win) | Next button | Enter |
| Daily puzzle card | Daily card | D (then Enter play, C copy, L back to levels, Esc close) |
| Play the album's next set picture | Album > Play | Enter in the album |

Starting a stroke on a cell that already has the current mark erases that
mark along the stroke instead. **Check** briefly highlights wrong fills; there
is no penalty beyond the star (free mode). The timer starts on your first move and best times
are kept per level.

The first launch shows a skippable "How to play" card (Enter/Space next, Esc
skip, arrows move between steps); the `?` button in the top bar reopens it and
the timer is paused while it is open.

Sound effects (fill, mark, undo, line done, mistake, star, level up, solved)
and a gentle music-box loop play on every platform; the speaker button next
to `?` mutes both and the choice is saved locally. On the web the music
starts after your first click or key press and pauses while the tab is
hidden. CrazyGames builds also follow the portal mute setting.

Progress (levels, best times, stars, XP, theme, board in progress, daily
streak/board/result under `daily`, rewarded album sets under `setsAwarded`)
is kept under one local key, `nonogrid_progress_v2`; saves from earlier
versions are migrated automatically and damaged optional fields fall back to
defaults. On CrazyGames this key syncs through the SDK Data module.

### Levels

- New levels use independently randomized, persisted seeds. Existing saves retain
  their previously exposed puzzles, including the original first three pictures.
- Grid difficulty grows from 5x5 to
  7x7, 8x8, 10x10, 12x12 and 15x15 (level 46+).
- See `harness/adrs/adr-line-solvable-generator.md` for how the generator
  and line solver guarantee a unique, guess-free solution.

## Run, test, build

Requires Flutter 3.41 (stable) or newer.

```sh
flutter pub get
flutter run -d chrome          # or an iOS/Android device
flutter analyze
flutter test
flutter build web --release --base-href /NonoGrid/
```

Pushing to `main` builds and deploys the web app to GitHub Pages via
`.github/workflows/deploy-pages.yml` (enable Pages with "GitHub Actions" as
the source in the repository settings).

## CrazyGames build

`tool/build_crazygames.sh` builds `build/nono-grid-crazygames.zip` for the CrazyGames portal (SDK gameplay events, no ads). See `docs/crazygames.md`.

## GamePix build

`tool/build_gamepix.sh` builds `build/nono-grid-gamepix.zip` for GamePix (no portal SDK, no ads, relative resources). See `docs/gamepix.md`.

## Sounds

Generated by `tool/generate_sounds.py` (Python 3 standard library only, deterministic), no third-party audio. Run `python3 tool/generate_sounds.py` to regenerate `assets/audio/*.wav`. The music loop is 16 kHz mono (about 0.8 MB).

## Fonts

Roboto (Regular, Medium, Bold, Black) is bundled in `assets/fonts/` so web builds never fetch it from fonts.gstatic.com. Roboto is licensed under Apache 2.0, see `assets/fonts/Roboto_LICENSE.txt`.

## Project layout

- `lib/src/logic/` - widget-free rules: clues, line/grid solver, seeded PRNG,
  puzzle generator, game state (strokes, undo, win).
- `lib/src/art/` - code-drawn paper/ink themes, craft desk scenery, picture
  thumbnails (no image assets).
- `lib/src/meta/` - stars, par time, XP curve, theme unlocks, daily
  puzzle/streak rules and album sets.
- `lib/src/share/` - clipboard copy with a web `execCommand` fallback.
- `lib/src/ui/` - board painter and effects, game screen, overlays.
- `lib/src/audio/` - sound effects and music loop (web HTML audio, native channel) and the mute store.
- `lib/src/storage.dart` - local persistence (shared_preferences, v1 migration).
- `harness/` - spec, ADRs, rules and contracts used for spec-driven work.
